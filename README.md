# GPT2-Controllable-Text-Generation
NLP课程期末项目：基于中文GPT2实现可控文本生成——解码策略与采样温度的对比实验分析

---

## 项目简介
本项目为NLP课程期末实训项目，以轻量级中文GPT-2预训练模型 `uer/gpt2-chinese-cluecorpussmall` 为基础，构建了一套完整的可控文本生成实验框架。项目核心目标是通过多组对照实验，系统探究**解码策略**与**采样温度**两大关键因素对中文文本生成效果的影响规律，深入理解自回归语言模型的生成机制与行为边界，为中文可控文本生成任务提供可复现的实验参考。

---

## 实验内容
- **解码策略对比实验**：对比贪婪搜索、束搜索、Top-k采样、Top-p（核采样）四种主流解码算法在中文续写任务中的表现差异
- **采样温度梯度实验**：设置多组温度参数（0.2/0.5/0.8/1.1），探究温度系数对生成文本风格、多样性与逻辑性的影响
- **多维度效果评估**：从文本流畅度、主题一致性、内容多样性、语句重复率、逻辑连贯性五个维度进行综合评价
- **实验结果可视化**：通过柱状图直观呈现不同参数下的文本生成效果差异，量化对比实验结论

## 核心结论
1.  **解码策略的表现差异**
    - **贪婪搜索**：生成文本语法严谨、无逻辑错误，主题一致性表现突出，但输出结果完全固定，多样性为0，仅适合对生成结果确定性要求极高的场景。
    - **束搜索**：在流畅度与连贯性上表现最优，生成文本几乎无语法错误，但随着束宽增大，文本多样性显著下降，易出现内容同质化问题，整体风格偏向保守。
    - **Top-k/Top-p采样**：在多样性上表现显著优于前两种策略，生成文本创意性更强，但对参数设置更为敏感，易出现逻辑断裂、语句重复、主题偏移等问题。

2.  **采样温度的影响规律（与实验结果完全对应）**
    - **低温度区间（0.2-0.5）**：模型输出趋于保守，高频词被反复选择，文本重复率明显升高，多样性较差，但主题一致性极强，续写内容与前文高度贴合。
    - **适中温度区间（0.6-0.8）**：生成文本在流畅度与多样性之间达到了最佳平衡，既保证了语句通顺连贯，又避免了重复输出，同时保留了一定的创意性，是本次实验中表现最优的参数区间。
    - **高温度区间（>1.0）**：模型随机性过强，生成文本易出现无意义乱码、逻辑混乱、主题漂移等问题，实用性大幅降低，仅适用于创意发散类场景。

3.  **综合对比与最优方案**
    结合实验数据与可视化结果来看，**Top-k/Top-p采样+适中温度（0.6-0.8）** 的组合在本次中文续写任务中表现最优，兼顾了文本的流畅度、多样性与主题一致性；而束搜索在追求文本严谨性的场景下仍具有不可替代的优势。
